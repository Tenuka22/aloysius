# Design System: St. Aloysius' College

## Color Palette

- **Green Dark:** #013405 - primary backgrounds, main sections
- **Green Darker:** #062B0A - deeper sections and overlays
- **Gold:** #FFB203 - accents, highlights, CTAs
- **Gold Light:** #FFD45A - hover states and secondary accents
- **Cream:** #FFF8E7 - light backgrounds, content areas
- **Cream Light:** #FFFEF6 - cards and elevated surfaces
- **Black:** #000000 - high contrast text
- **Red Brand:** #A51919 - brand alerts
- **Red Alert:** #E05252 - destructive actions and warnings
- **Text:** Dark green (#013405) on light backgrounds, cream/gold on dark backgrounds

## Typography

- **Font Family (Headings):** Playfair Display Variable (serif)
- **Font Family (Body):** Manrope Variable (sans-serif)
- **Weights:** Light (300), Regular (400), Medium (500), Semibold (600), Bold (700)

## Layout Principles

- **Brutalist Corners:** Sharp, angular edges with no border-radius
- **Grid System:** Responsive grid with consistent spacing
- **Sections:** Distinct visual hierarchy between sections
- **Spacing:** Generous padding and margins for readability

## Component Patterns

- **Cards:** Sharp corners, subtle borders, hover effects
- **Buttons:** Sharp corners, solid colors, clear hierarchy
- **Badges/Tags:** Sharp corners, uppercase text, bold styling
- **Navigation:** Clean, minimal, functional

## Visual Hierarchy

1. Hero section with large typography
2. Stats with icons and values
3. Content sections with clear headings
4. Call-to-action buttons with gold accents

## Animation

- GSAP for scroll-triggered animations
- Subtle fade-in and slide effects
- Smooth transitions on hover states
